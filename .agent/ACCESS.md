# Anonymous agent access

This public repository is intentionally readable without GitHub authentication.

- Canonical repository: https://github.com/iteathen/iteathen.github.io
- Public Pages endpoint: https://iteathen.github.io/llms.txt
- Default branch: `main`
- Anonymous Git clone: `https://github.com/iteathen/iteathen.github.io.git`
- Raw-file base: `https://raw.githubusercontent.com/iteathen/iteathen.github.io/main/`
- ZIP snapshot: `https://codeload.github.com/iteathen/iteathen.github.io/zip/refs/heads/main`
- tar.gz snapshot: `https://codeload.github.com/iteathen/iteathen.github.io/tar.gz/refs/heads/main`

No GitHub credential, account, connector, or REST API is required for read-only access.

The authoritative account-wide index is maintained in `iteathen/.github/llms.txt`; this repository is its static publication mirror.
